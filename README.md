Entry for the make.fun bounty **Dad Joke Showdown** (`u-mfnakmal-dad-joke-showdown-1d2ce3e5`).

`main.ts` writes a single dad joke — a dad, his dog, and a name that backfires every single day — to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). The joke is plain ASCII, exactly one line with no trailing newline, and well under the 200-character limit.

Run it with:

```sh
node main.ts
```
